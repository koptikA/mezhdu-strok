# Тестовое задание — продуктовый дизайнер, корпоративная B2E-платформа

Продукт: корпоративная B2E-платформа.

В системе используется принцип «двух рук». Первая линия на основании бумажного
заявления клиента вводит данные торгового поручения в систему и отправляет его
на проверку. После этого сотрудник второй линии получает задачу на проверку
поручения и берёт её в работу.

Сотруднику второй линии доступны:
- данные торгового поручения, введённые первой линией в системе;
- скан бумажного заявления клиента (в виде прикреплённого документа);
- история заявления.

Сотрудник второй линии должен проверить корректность введённых данных, сравнив
их со сканом заявления клиента, и принять решение.

В интерфейсе должны отображаться следующие данные поручения, введённые первой
рукой: ФИО клиента, тип сделки, брокерский счёт, направление сделки, торговая
площадка, ISIN, эмитент, тип бумаги, количество бумаг, цена, сумма сделки,
срок окончания поручения и дата поручения.

Сотрудник второй линии должен иметь возможность:
- подтвердить операцию;
- вернуть поручение на уточнение с комментарием.

Как итог необходимо предоставить: экран задачи на проверку торгового поручения
и описать логику действий сотрудника. Можно использовать любой UI-кит.
