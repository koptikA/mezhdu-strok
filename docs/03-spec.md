# Спецификация · «Между строк»

Размер задачи: **квартира (T2)** — несколько функций, чужой сервис, хранение
нет, интерфейс, деплой. Режется на 4 куска. Глубина: «проработай глубоко».

## 1. Живой разбор (пункты 7, 7.1, 7.2)

`POST /api/analyze` принимает `{mode, text, profession, deadline}`, отвечает
потоком SSE: события `status` (идёт поиск), `thinking`, `text`, `error`, `done`.

Модель `claude-opus-5`, adaptive thinking, `display: "summarized"`, в рабочем
режиме включён веб-поиск `web_search_20260209` (до 6 обращений). Методика —
`core/analysis.md` или `core/personal.md` — уходит в `system` с
`cache_control`, чтобы повторный разбор стоил дешевле.

Продуманные ситуации, которых в брифе не было:

| Ситуация | Что делаем |
|---|---|
| Ключа нет на сервере | 500 с человеческим текстом до начала потока, не «Internal Error» |
| Текст короче 40 знаков | 400, кнопка не блокируется, введённое не теряется |
| Текст длиннее 20 000 знаков | 400 с просьбой оставить главное; порог назван в тексте ошибки |
| API отвалился в середине | Написанная часть остаётся на экране, снизу «разбор оборвался» |
| Двойной клик по «Разобрать» | Кнопка отключается на время разбора |
| Модель отказалась отвечать (`refusal`) | Отдельное сообщение, не молчание |
| Разбор идёт 1–3 минуты | Статус меняется: «Читаю» → «Разбираюсь в области» → «Думаю» → «Пишу разбор» |
| Vercel режет функцию по таймауту | `maxDuration` поднят до предела тарифа; при обрыве действует правило «часть уцелела» |

## 2. Интерфейс (пункты 8, 8.1, 10)

Одна страница, два режима. В личном режиме поля «кем работаешь» и «срок»
скрыты — они там бессмысленны.

- Пустое состояние: заголовок, одна фраза, что это, и поле. Никаких табличек до разбора.
- Ввели ерунду: подсказка под кнопкой, набранный текст сохраняется.
- Мобильный экран: одна колонка, поля во всю ширину, шрифт не меньше 16px.
- Дисклеймер внизу виден всегда, не только после разбора.
- Источник правды по виду — холст `design.pen`, код приводится к нему.

## 3. Страница-доказательство (пункт 9)

`public/case/` — статическая, **без обращений к API и без расходов**.
Показывает кейс go-invest: бриф → что предсказало ядро → реальное письмо-отказ →
совпадения. Это то, что смотрят судьи; она обязана работать без ключа.

## 4. Деплой (пункт 11)

Vercel, статика из `public/`, функция из `api/`. `ANTHROPIC_API_KEY` — в
переменных окружения проекта, не в коде и не в репозитории.

## 5. Сдача (пункт 12)

До 6 скриншотов, суммарно до 1,7 МБ. Описание 600 знаков. Ник в телеграме.
Пять кодовых слов — только от тебя. **Отправляется один раз**, поэтому перед
отправкой отдельная сверка вслух по этому списку.

## Границы

- Ничего не сохраняем: ни текстов, ни разборов. Хранилища в проекте нет.
- Регистрации нет, входа нет.
- Личный режим не валидируем эталоном — у него эталона не существует.
