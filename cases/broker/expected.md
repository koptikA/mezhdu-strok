# Ключ проверки: невысказанные ожидания, вытащенные из реального отказа

Каждый пункт — требование, по которому кандидата фактически судили,
но которого в брифе не было. Ядро «Подтекста» должно предсказать их,
видя ТОЛЬКО brief.md.

| # | Ожидание | Дословно из отказа |
|---|---|---|
| E1 | Аудит текущего решения должен заканчиваться **выводами**, а не описанием | «по аудиту текущего решения нет выводов» |
| E2 | Нужны **гипотезы, почему сейчас не продаёт** — опора для всех решений | «нет и гипотез, почему оно сейчас не продаёт — а это опора для всего остального» |
| E3 | Разобрать **сам продаваемый продукт** вглубь, а не рынок вокруг него | «до конца не разобрана сама услуга, которую мы продаём» |
| E4 | Любая новая идея — **с гипотезой**: зачем бизнесу, что изменится | «предлагать — хорошо, только подкрепляй гипотезой» |
| E5 | Не предлагать то, **чего нет в продукте**, без обоснования | «наследование капитала... в продукте, который мы продаём, этого нет» |
| E6 | Конкуренты — **отдельный артефакт-табличка**, а не заметки | «стоило собрать в отдельный артефакт — табличку» |
| E7 | Референсы должны иметь **объединяющую идею**, объяснённую словами | «не раскрыт смысл референсов: непонятно, от какой идеи ты шла» |
| E8 | Показать **связь референс → результат** | «не считывается, как выбранные референсы отразились в итоге» |
| E9 | Визуал не должен читаться как **чужой узнаваемый бренд** | «очень уж напоминают узнаваемый стиль Т-Банка» |
| E10 | Метафоры проверять на **достоверность в предметной области** | «пластиковая карта: к брокерскому счёту её не выпускают» |
| E11 | Концепт должен быть **связан воедино**, а не набор хороших кусков | «не хватило глубины... и в том, чтобы связать концепт воедино» |

## Что в брифе было написано прямо
- объяснить ценность услуги
- довести до целевого действия
- «как именно устроить страницу — решать тебе»

## Наблюдение
Кандидат выполнил ровно то, что просили, и вложился сверх нормы
(исследование, конкуренты, научные статьи, источники, калькулятор тарифа).
Отказ пришёл целиком по невысказанной части. Это и есть проблема,
которую решает продукт.
